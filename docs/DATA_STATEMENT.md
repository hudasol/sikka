# Data statement

## What data this repository contains

- **Synthetic feeds** in `data/samples/clean` and `data/samples/broken`, generated by `sikka generate` from seed 20260422. The broken set is the clean set with every catalogued fault injected at 3 percent.
- **Generated artefacts**: contract schemas (`contract/`), documentation (`docs/CONTRACT.md`, `docs/RULES.md`, `docs/EVALUATION.md`), the static snapshot for the web app (`web/public/snapshot`), and evaluation results (`results/*.json`).
- **No real data.** There are no real crash, traffic or road records, no real personal data, and no scraped data. Corridor names and producer names are invented. Values that look like personal data in the broken samples (used to test the privacy rules) are fake: zero filled plates, the name "Synthetic Person", and phone and identity numbers built from zeros or random digits.

## How the synthetic world is built

- 6 invented corridors with 40 segments each, 0.5 to 12 kilometres long, on a local grid placed inside the UAE bounding box. The geometry does not follow any real road.
- Daily traffic per segment from a lognormal base with a random walk along each corridor; weekday and hourly profiles; counting stations at about 60 percent of segments, recorded hourly for one week.
- Crashes per segment from a negative binomial process (gamma heterogeneity with shape 3 and Poisson counts) with mean proportional to traffic to the power 0.85 and to length, with class and lane effects, over 2021 to 2025. Twelve segments carry a hazard multiplier between 2 and 4 (planted blackspots). The intercept is calibrated so that about 3,500 crashes are expected over five years.
- Four invented producers observe the crashes with their own detection rates, coordinate and time noise, reporting delays and coverage (`src/sikka/synth/config.py`).
- The ground truth (true rates, planted blackspots, which record carries which fault, which reports describe the same crash) is written to `build/` by `sikka generate` and is never committed. Only the evaluation harness reads it.

## Intended use

Demonstration, testing and discussion of a data contract and ranking method. The data must not be presented as describing any real road, place, producer or person.
