# Field dictionary, contract v1.0.0

> Generated by `sikka docs build` from `sikka.contract`. Do not edit by hand.

This dictionary describes the open data contract that Sikka checks. Every feed in
this repository is synthetic. The contract is a proposal and has not been adopted
by any entity.

> The Arabic descriptions are a machine drafted first version. They need review by a
> native speaker before any use outside this repository.

## Conventions

| Topic | Convention |
| --- | --- |
| coordinates | WGS84 (EPSG:4326), lat and lon in decimal degrees |
| timestamps | ISO 8601 in UTC with a trailing Z |
| local time zone | Asia/Dubai (UTC+04:00); never assumed for timestamps |
| distance unit | metres |
| speed unit | km/h |
| percentages | 0 to 100 |
| identifiers | opaque strings matching ^[A-Z0-9_\-]{3,40}$ |
| missing values | absent from the record; never null, -1, 0 or N/A |
| header | every feed file starts with a provenance header under the key sikka_header |

Plausible coordinates lie inside latitude 22.5 to 26.5 and longitude 51.0 to 56.5.

## Prohibited fields

These field names must never appear in a feed. Matching ignores case and separators.
Records that carry them are quarantined and their values are never displayed.

`name`, `full_name`, `first_name`, `last_name`, `driver_name`, `person_name`, `emirates_id`, `national_id`, `id_number`, `passport_number`, `phone`, `phone_number`, `mobile`, `email`, `plate`, `plate_number`, `licence_plate`, `license_plate`, `narrative`, `description`, `notes`, `comments`, `free_text`
